# Muhammad Haseeb · Portfolio

Personal portfolio site of Muhammad Haseeb, a Computer Information Systems Engineering student at NED University of Engineering and Technology, Karachi.

**Live site:** https://smith-willson.github.io

## What's on the site

- Selected projects, each linking to its GitHub repository
- Education and programs (NED University, CIS Community ZeroToShip 2026)
- Skills
- Contact details

## Built with

- Plain HTML and CSS in a single file (`index.html`)
- No framework, no build step, no dependencies
- Fonts: Inter, Inter Tight and IBM Plex Mono, loaded from Google Fonts

## Run locally

```bash
git clone https://github.com/smith-willson/smith-willson.github.io.git
cd smith-willson.github.io
```

Open `index.html` in a browser. No server is needed.

## Deploy on GitHub Pages

1. Name the repository exactly `smith-willson.github.io`.
2. Push `index.html` and this `README.md` to the `main` branch.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. After a minute or two the site is live at `https://smith-willson.github.io`.

## Edit the content

Everything is in `index.html`. Search for these sections:

| To change | Look for |
|---|---|
| Name and headline | `<header class="hero">` |
| Projects | `<div class="plist">` |
| Education | `<h2 id="h-edu">` |
| Skills | `<div class="skills">` |
| Email and links | `<section class="sec contact"` |

Colors and fonts are defined as variables at the top of the `<style>` block.
